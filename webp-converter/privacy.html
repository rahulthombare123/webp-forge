Privacy Policy

Your Data Stays With You.
Always.

WebP Forge was built with a single privacy principle: we never see your images. Here's exactly how that works.

Last updated: June 2025 · Created by Rahul Thombare

🔒

The Short Version

WebP Forge converts images entirely inside your browser using the Canvas API. No image data, file names, or any user content is ever sent to a server, stored in a database, logged, or shared with anyone — including us.

1. What Data We Collect

None. This tool is 100% client-side. When you drop or browse an image:

  • The file is read locally by your browser using the FileReader API
  • It is drawn to an in-memory <canvas> element
  • The WebP blob is generated locally via canvas.toBlob()
  • The file is downloaded directly to your device
  • No data leaves your browser at any point in this process

2. Cookies & Local Storage

WebP Forge does not use cookies, localStorage, sessionStorage, IndexedDB, or any browser storage mechanism to persist your data or identify you between visits.

When you close the tab, everything is gone. Nothing is retained.

3. Third-Party Services

The only external resource loaded is JSZip from cdnjs.cloudflare.com, and only when you click "Download All as ZIP". This is a JavaScript library — it does not receive your images in any form.

Google Fonts are loaded for typography. Google may log the request (as with any CDN), but no image data is involved.

We do not use analytics, tracking pixels, advertising scripts, or any third-party data collection of any kind.

4. Server Logs

If you host WebP Forge on a web server, your server may log standard HTTP request metadata (IP address, browser type, page visited). This is standard web server behavior unrelated to this tool. Image files themselves are never sent to the server.

If you open index.html directly from your file system (file://), there are zero network requests other than Google Fonts and JSZip on demand.

5. Children's Privacy

WebP Forge is a developer utility tool. We do not knowingly collect any information from anyone, including minors. Since no data is collected at all, there is nothing to disclose here beyond confirming that fact.

6. Changes to This Policy

If the tool ever changes in a way that affects data handling, this page will be updated with a new "Last updated" date. The core principle — no data collection — will not change without explicit, prominent notice.
